## 📖 Overview

Power BI dashboard project focused on customer demographics and risk-related indicators. This README documents the intended workflow and the files available in the repository. Verify all outputs against the current code and data before using them as evidence.

## 🎯 Problem Statement

Stakeholders need a clear view of customer patterns, but churn and risk must be defined consistently before interpreting results.

## 🎯 Objectives

- Define churn and risk based on the available data.
- Review customer-group KPIs and filters.
- Summarize evidence and limitations for stakeholders.

## ✨ Features

## 🔄 Project Workflow

1. Open Churn and Customer Risk Analysis.pbix in Power BI Desktop.
2. Check the data source, refresh status, and available columns.
3. Define what churn and customer risk mean in this dataset.
4. Review KPI formulas, denominators, filters, and reporting periods.
5. Compare customer groups while checking group sizes and missing data.
6. Write a stakeholder summary separating observed patterns from recommendations.
